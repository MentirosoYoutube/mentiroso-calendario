# Documentación del calendario

Este repositorio público contiene únicamente el sitio y sus datos autorizados.
Las preferencias, investigaciones y documentación interna se mantienen fuera del repositorio público. No copiarlas aquí ni en issues, commits, ramas, pull requests o archivos del despliegue.

Para actualizar el calendario, consultar AGENTS.md y juegos.json. Si una tarea requiere contexto interno, obtenerlo en la conversación o fuente privada autorizada; no recuperarlo del historial público como fuente vigente.
